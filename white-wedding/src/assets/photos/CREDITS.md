# Photo credits

Placeholders for the couple's own photographs. Every file here is from
Unsplash, whose licence permits commercial use with no attribution
required — recorded anyway, because it makes each file traceable and
replaceable.

To swap in the real photographs, drop them into this folder under the
same filenames. No code changes: `src/config/photos.js` resolves by
filename, and a missing file falls back to the section's own gradient
rather than a broken image.
